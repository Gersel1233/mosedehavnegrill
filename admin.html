Køkken-kø

kun bordene — køen opdaterer sig selv

Ét tryk pr. trin: Modtaget → Tilberedes → Klar → Serveret.

Slår I det fra, møder nye scanninger "kom op til lugen". Bestillinger, der allerede er i køen, kører færdigt. Det er en anden kontakt end den på Bestillinger: der kan være åbent for mad ud af huset, mens I ikke kan nå at servere ved bordene.

Er kvarteret fyldt, får gæsten "der er run på lige nu — prøv igen om lidt, eller kom op til lugen". Det er noget andet end lukket: bordene, der ikke har bestilt endnu, kan stadig komme til. Tomt felt = intet loft. Gælder kun bordene — mad ud af huset bestilles dagen før og rører ikke lugen nu.

Lyden er slået fra. Nye ordrer markeres stadig på skærmen.
